# sistema-de-controle-de-estoque
Sistema de controle de estoque desenvolvido em Python para praticar lógica de programação, estruturas de dados, funções e manipulação de dados em memória.

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação e consolidar conhecimentos em Python através da criação de um sistema de controle de estoque executado no terminal.

Durante o desenvolvimento, o foco foi aplicar conceitos fundamentais da linguagem, como estruturas de repetição, condicionais, funções, tratamento de exceções, manipulação de dicionários e organização do código em módulos lógicos. Além disso, houve uma preocupação em tratar entradas inválidas do usuário e criar um fluxo de navegação intuitivo.

## Funcionalidades

- Cadastro de produtos
- Listagem de todos os produtos cadastrados
- Busca de produtos por nome
- Visualização detalhada das informações de um produto
- Edição de nome, categoria e preço
- Entrada de estoque
- Saída de estoque
- Remoção de produtos
- Validação de entradas do usuário
- Tratamento de erros utilizando `try` e `except`

## Tecnologias utilizadas

- Python

## Conceitos praticados

- Funções
- Estruturas de decisão
- Estruturas de repetição
- Dicionários
- Manipulação de dados
- Tratamento de exceções
- Validação de entradas
- Organização de código
- Fluxo de menus
- Passagem de parâmetros entre funções

Este projeto faz parte do meu processo de aprendizado em Python e representa um passo importante na construção de uma base sólida em programação.
